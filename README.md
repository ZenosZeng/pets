# 线条小狗桌宠

> Windows 本地桌面宠物｜当前版本：`v0.1.0`

一只安静常驻在桌面右下角的线条小狗桌宠。支持小白、小鸡毛，以及小白和小鸡毛一起出现。

## 功能

- 三种角色状态：小白、小鸡毛、小白 + 小鸡毛
- 每种状态包含多个随机动画，并尽量避免连续重复
- 无操作 20～60 秒后自动更换当前角色的动作
- 透明、无边框、始终置顶，不显示在任务栏
- 固定 `154×154` 显示区域，所有动画自动等比适配并底部居中
- 透明区域点击穿透，不影响桌面和其他窗口的操作
- 支持鼠标拖动，并自动保存上次位置和角色状态
- Windows 通知区域图标可控制显示、隐藏、暂停、换动作和退出
- 每 40 分钟提醒活动一次、喝水一次，两种提醒错开 20 分钟
- 支持即时测试活动提醒和喝水提醒
- 损坏或缺失的动画会自动跳过，不影响程序继续运行

## 操作

| 操作 | 效果 |
|---|---|
| 左键单击桌宠 | 随机切换角色状态和动画 |
| 左键拖动 | 移动桌宠 |
| 右键桌宠 | 换动作、暂停、测试提醒、切换角色或退出 |
| 单击通知区域图标 | 显示或隐藏桌宠 |
| 右键通知区域图标 | 打开完整控制菜单 |

隐藏桌宠后程序仍会在通知区域运行。需要彻底关闭时，请选择“退出程序”。
