# 桌宠动画素材

三个状态各自对应一个目录，每个目录都可以放任意数量的 GIF：

```text
assets/
├─ xiaobai/
│  ├─ solo.gif
│  ├─ laptop.gif
│  └─ ...
├─ xiaojimao/
│  ├─ corner.gif
│  └─ ...
└─ together/
   ├─ cuddle.gif
   ├─ dance.gif
   └─ ...
```

文件名没有固定要求，只要扩展名为 `.gif`。进入某个角色状态时，程序会从对应目录随机选择动画；如果有多个，会尽量避免连续两次选择同一个文件。

建议使用透明背景 GIF。新增或替换素材后，在项目根目录运行：

```powershell
pixi run normalize-assets
```

工具会原地将所有 GIF 统一到 `220×220` 透明画布，把动画所有帧的可见区域等比缩放或放大到填满画布的一条边，并整体放在底部中央。运行前请自行保留原文件备份。

程序仍可读取其他尺寸的 GIF：素材规范画布为 `220×220`，桌宠显示窗口为 `154×154`。每次切换时会保持宽高比自动适配并底部居中。统一素材可以进一步避免不同 GIF 自带透明边距导致的视觉大小差异。

现有下载素材的页面来源和规格记录在 `SOURCES.md`。
