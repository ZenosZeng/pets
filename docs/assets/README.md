# README 首图

`readme-cover.png` 使用内置 `image_gen` 生成，仅用于项目 README 展示，不是实际界面截图。文件位于文档目录，没有加入运行时动画目录。

## 素材来源

生成时使用现有[角色联系表](../../assets/together-contact-sheet.png)作为外形和画风参考，保留小白、小鸡毛的线条形象。原动画来自 Tenor，来源及使用范围见 [SOURCES.md](../../assets/SOURCES.md)。生成横幅不改变第三方角色或动画的版权，也不代表取得额外授权。

没有修改、覆盖原 GIF，没有输入个人桌面、文件、聊天或配置。
